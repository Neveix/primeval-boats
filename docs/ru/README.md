# Primeval Boats

Контент-пак для [VoxelCore](https://github.com/MihailRis/voxelcore), который добавляет деревянные лодки, плоты и байдарки с плавной физикой воды — крен, плавучесть и всплески.

*Примечание: ридми файл написан с помощью ИИ.*

## Возможности

- **Несколько типов лодок** - стандартная лодка, плот из брёвен, байдарка
- **Реалистичная физика**
- [RideableAPI](https://github.com/Neveix/voxelcore-rideable-api) для возможности пересаживаться с лодки на [другие объекты](https://github.com/Neveix/voxelcore-resties)
- **Инвентарь** - хранение предметов внутри некоторых лодок
- **Интеграция с [New-Generation](https://github.com/EsPaKira/New-Generation)**
- **Водяные всплески** — визуальный эффект при движении или падении

## Установка

- VoxelCore >=0.31.4

- Убедитесь, что установлены зависимости:
   - [RideableAPI](https://github.com/Neveix/voxelcore-rideable-api)
   - [Interactive Commons](https://github.com/Neveix/voxelcore-interactive-commons)

- Дополнительные зависимости:
   - [New-Generation](https://github.com/EsPaKira/New-Generation) (>=0.6.0)

## Для игроков

- **Плот** - дешёвый, медленный, но вместительный
- **Лодка** - классический выбор для исследования
- **Байдарка** - быстрая и манёвренная, но без места для хранения

**Управление:**
- `WASD` - движение
- `ПКМ` - сесть
- `ПКМ + Shift` - открыть инвентарь (если у лодки есть хранилище)
- `Shift` - слезть

### Рецепты крафта


| Лодка | Рецепт |
| :--- | :--- |
| **Плот из брёвен** | 4 Древесины + 20 Соломы |
| **Дощатая лодка** | 10 Досок + 2 Самородка оловянной бронзы + 10 Кусков красной глины |
| **Байдарка** | 20 Костей + 4 Шкуры |

## Для разработчиков

Этот пак построен на основе [Interactive Commons](https://github.com/Neveix/voxelcore-interactive-commons) (`intcom`) и демонстрирует его возможности.

### Что показывает этот пак

- Как настраивать параметры лодки (скорость, ускорение, крен)
- Как переопределять поведение по умолчанию через `modules/intcom/boat/`
- Как добавлять поддержку инвентаря

### Создавайте свои лодки

Вы можете легко добавлять собственные лодки в свой пак.

Просто воспользуйтесь документацией [Interactive Commons](https://github.com/Neveix/voxelcore-interactive-commons)
